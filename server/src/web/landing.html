How it works

1

Encrypt locally

A random 256-bit key encrypts the file on your machine. Even the filename is encrypted.

2

Share a link

The server stores only ciphertext. The key lives in the #fragment, which is never sent to the server.

3

It self-destructs

After N views or 10 min to 24 h, the blob is deleted. You can revoke any time.

.gitignore guard

Warns before you share a file that git could pick up, or one that's already tracked. One click fixes it.

Masked diff on pull

See which keys are added, changed or removed, with values hidden. Merge only what you choose.

Pre-commit warning

Catches staged .env files and AWS, GitHub, Stripe and Slack tokens before they leave your laptop.

Open source

Small and auditable, with an honest threat model. Self-host with Docker or Cloudflare Workers.
